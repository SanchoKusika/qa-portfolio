# BUG-014. [Каталог] Цена отображается с одним знаком после точки

| Поле | Значение |
|---|---|
| Severity | Minor |
| Priority | Low |
| Модуль | Каталог |
| Пользователь | `visual_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Иногда: зависит от случайной цены, см. [BUG-013](BUG-013.md) |
| Связанный тест-кейс | [TC-INV-01](../test-cases/saucedemo-test-cases.md#tc-inv-01-отображение-каталога) |

## Предусловия

- Выполнен вход под `visual_user`

## Шаги воспроизведения

1. Открыть каталог
2. Посмотреть на цену Sauce Labs Backpack (или другого товара, у которого цена оканчивается на 0)

## Фактический результат

Цена отображается как `$26.1`.

## Ожидаемый результат

Цена всегда с двумя знаками после точки: `$26.10`.

Отдельный дефект форматирования: даже если исправить случайные цены из BUG-013, форматирование нужно проверить отдельно для цен, оканчивающихся на 0.
