# BUG-001. [Каталог] У всех товаров одно и то же изображение

| Поле | Значение |
|---|---|
| Severity | Major |
| Priority | High |
| Модуль | Каталог |
| Пользователь | `problem_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда |
| Связанный тест-кейс | [TC-INV-01](../test-cases/saucedemo-test-cases.md#tc-inv-01-отображение-каталога) |

## Предусловия

- Выполнен вход под `problem_user`

## Шаги воспроизведения

1. Открыть каталог `/inventory.html`
2. Посмотреть на изображения товаров

## Фактический результат

У всех 6 товаров одинаковое изображение: фото собаки. Во всех карточках в атрибуте `src` указан один и тот же файл `/assets/sl-404-*.jpg`.

## Ожидаемый результат

У каждого товара свое изображение, соответствующее названию, как под `standard_user`: рюкзак, фонарь, футболка и т. д.

## Вложения

![Одинаковые изображения в каталоге](img/BUG-001-same-images.jpg)

## Дополнительно

Имя файла `sl-404` говорит о том, что вместо изображений товаров подставляется заглушка для ненайденного ресурса. На странице карточки товара изображение отображается (см. [BUG-003](BUG-003.md)), то есть дефект проявляется в каталоге.
