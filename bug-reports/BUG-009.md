# BUG-009. [Каталог] Remove в каталоге не удаляет товар, в Console ошибка «Failed to remove item from cart»

| Поле | Значение |
|---|---|
| Severity | Major |
| Priority | Medium |
| Модуль | Каталог, корзина |
| Пользователь | `error_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда |
| Связанный тест-кейс | [TC-CART-02](../test-cases/saucedemo-test-cases.md#tc-cart-02-удаление-товара-на-странице-корзины) |

## Предусловия

- Выполнен вход под `error_user`
- В корзине Backpack, Bike Light и Onesie (счетчик «3»)
- Открыт DevTools, вкладка Console

## Шаги воспроизведения

1. В каталоге нажать Remove у товара «Sauce Labs Backpack»

## Фактический результат

Счетчик остается «3», кнопка остается Remove. В Console исключение:

```
Error: Failed to remove item from cart.
    at p (https://www.saucedemo.com/assets/index-D3OxT1jE.js:573:45969)
```

То же для Bike Light и Onesie.

## Ожидаемый результат

Товар удален из корзины, счетчик «2», кнопка сменилась на Add to cart.

## Вложения

Скриншот совпадает с [BUG-008](img/BUG-008-add-to-cart-error.jpg): состояние каталога после клика по Remove не меняется.

## Дополнительно

На странице корзины `/cart.html` кнопка Remove работает, это обходной путь. Аналогичный дефект под `problem_user`: [BUG-005](BUG-005.md).
