# BUG-019. [Корзина] Кнопка Checkout отображается в правом верхнем углу шапки

| Поле | Значение |
|---|---|
| Severity | Minor |
| Priority | Medium |
| Модуль | Корзина |
| Пользователь | `visual_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/cart.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда |
| Связанный тест-кейс | [TC-CHK-01](../test-cases/saucedemo-test-cases.md#tc-chk-01-успешное-оформление-заказа) |

## Предусловия

- Выполнен вход под `visual_user`, в корзине есть товар

## Шаги воспроизведения

1. Открыть корзину

## Фактический результат

Кнопка Checkout находится в правом верхнем углу страницы, в шапке, и наполовину обрезана верхним краем окна. Внизу корзины, рядом с Continue Shopping, кнопки нет. Кнопка кликабельна, оформление открывается.

## Ожидаемый результат

Кнопка Checkout внизу корзины справа, напротив Continue Shopping, как под `standard_user`.

## Вложения

![Checkout в правом верхнем углу](img/visual-user-cart.jpg)

## Дополнительно

Пользователь, который ищет кнопку оформления под списком товаров, не найдет ее. Поэтому priority Medium, хотя кнопка работает.
