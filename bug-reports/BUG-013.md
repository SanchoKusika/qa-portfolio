# BUG-013. [Каталог] Цены в каталоге случайные и не совпадают с ценами в корзине

| Поле | Значение |
|---|---|
| Severity | Critical |
| Priority | High |
| Модуль | Каталог, корзина |
| Пользователь | `visual_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда, значения меняются при каждой загрузке каталога |
| Связанный тест-кейс | [TC-INV-04](../test-cases/saucedemo-test-cases.md#tc-inv-04-открытие-карточки-товара), [TC-CHK-04](../test-cases/saucedemo-test-cases.md#tc-chk-04-расчет-итоговой-суммы-заказа) |

## Предусловия

- Выполнен вход под `visual_user`, корзина пуста

## Шаги воспроизведения

1. Открыть каталог и запомнить цены товаров
2. Войти заново и снова открыть каталог, сравнить цены
3. Добавить в корзину Sauce Labs Backpack и Sauce Labs Bike Light
4. Открыть корзину

## Фактический результат

Цены в каталоге при каждой загрузке разные и не совпадают с ценами `standard_user`. В корзине цены другие:

| Товар | Каталог, загрузка 1 | Каталог, загрузка 2 | Корзина | `standard_user` |
|---|---|---|---|---|
| Sauce Labs Backpack | $49.92 | $26.1 | $29.99 | $29.99 |
| Sauce Labs Bike Light | $3.44 | $97.01 | $9.99 | $9.99 |
| Sauce Labs Bolt T-Shirt | $38.54 | $92.54 | — | $15.99 |
| Sauce Labs Fleece Jacket | $6.97 | $19.26 | — | $49.99 |
| Sauce Labs Onesie | $30.65 | $72.87 | — | $7.99 |
| Test.allTheThings() T-Shirt (Red) | $80.12 | $15.94 | — | $15.99 |

Покупатель выбирает товар по одной цене, а при оформлении видит другую. Итог заказа считается по ценам корзины: Item total $39.98, Tax $3.20, Total $43.18.

## Ожидаемый результат

Цена товара одинакова в каталоге, в карточке, в корзине и в заказе, и не меняется при перезагрузке страницы.
