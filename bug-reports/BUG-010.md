# BUG-010. [Оформление] Поле Last Name не принимает ввод

| Поле | Значение |
|---|---|
| Severity | Major |
| Priority | High |
| Модуль | Оформление заказа |
| Пользователь | `error_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/checkout-step-one.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда |
| Связанный тест-кейс | [TC-CHK-01](../test-cases/saucedemo-test-cases.md#tc-chk-01-успешное-оформление-заказа) |

## Предусловия

- Выполнен вход под `error_user`, в корзине есть товар
- Открыта форма Checkout: Your Information

## Шаги воспроизведения

1. Ввести `Ivan` в поле First Name
2. Кликнуть в поле Last Name и ввести `Petrov`

## Фактический результат

Поле Last Name остается пустым, введенный текст не появляется. First Name и Zip/Postal Code принимают ввод нормально.

## Ожидаемый результат

В поле Last Name отображается `Petrov`.
