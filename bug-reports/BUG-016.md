# BUG-016. [Шапка] Иконка корзины смещена вниз из шапки к списку сортировки

| Поле | Значение |
|---|---|
| Severity | Minor |
| Priority | Medium |
| Модуль | Шапка сайта |
| Пользователь | `visual_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда, на всех страницах |
| Связанный тест-кейс | [TC-INV-01](../test-cases/saucedemo-test-cases.md#tc-inv-01-отображение-каталога) |

## Предусловия

- Выполнен вход под `visual_user`

## Шаги воспроизведения

1. Открыть каталог
2. Посмотреть на иконку корзины в правом верхнем углу

## Фактический результат

Иконка корзины смещена влево и вниз: она находится под линией шапки, вплотную над списком сортировки. Под `standard_user` иконка стоит в правом углу шапки на одной линии с заголовком Swag Labs. Иконка кликабельна, корзина открывается.

## Ожидаемый результат

Иконка корзины в правом углу шапки, как под `standard_user`.
