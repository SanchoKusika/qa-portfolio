# BUG-025. [Оформление] Нулевая сумма товаров отображается как «$0» без копеек

| Поле | Значение |
|---|---|
| Severity | Trivial |
| Priority | Low |
| Модуль | Оформление заказа |
| Пользователь | `standard_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/checkout-step-two.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда, при пустой корзине |
| Связанный тест-кейс | [TC-CHK-04](../test-cases/saucedemo-test-cases.md#tc-chk-04-расчет-итоговой-суммы-заказа) |

## Предусловия

- Выполнен вход под `standard_user`, корзина пуста

## Шаги воспроизведения

1. Открыть корзину, нажать Checkout
2. Заполнить форму валидными данными, нажать Continue
3. Посмотреть блок Price Total

## Фактический результат

`Item total: $0`, при этом `Tax: $0.00` и `Total: $0.00`.

## Ожидаемый результат

Все суммы в одном формате с двумя знаками после точки: `Item total: $0.00`.
