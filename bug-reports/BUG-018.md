# BUG-018. [Каталог] Кнопка Add to cart у Test.allTheThings() T-Shirt (Red) выходит за край карточки

| Поле | Значение |
|---|---|
| Severity | Minor |
| Priority | Low |
| Модуль | Каталог |
| Пользователь | `visual_user` |
| Окружение | Windows 11, Chrome 155, окно 1920×889 |
| URL | https://www.saucedemo.com/inventory.html |
| Дата | 2026-10-12 |
| Воспроизводимость | Всегда |
| Связанный тест-кейс | [TC-INV-01](../test-cases/saucedemo-test-cases.md#tc-inv-01-отображение-каталога) |

## Предусловия

- Выполнен вход под `visual_user`

## Шаги воспроизведения

1. Открыть каталог
2. Посмотреть на кнопку Add to cart у товара Test.allTheThings() T-Shirt (Red), правый нижний товар

## Фактический результат

Кнопка сдвинута вправо на 54 px относительно кнопок других товаров и выходит за правую границу карточки. В DevTools у кнопки есть дополнительный класс `btn_inventory_misaligned`, которого нет у остальных кнопок.

## Ожидаемый результат

Кнопка внутри карточки, на одной вертикали с кнопкой Add to cart товара над ней.
