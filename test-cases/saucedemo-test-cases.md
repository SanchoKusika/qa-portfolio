# Тест-кейсы: Swag Labs

Сайт: https://www.saucedemo.com/. Пароль для всех учетных записей: `secret_sauce`.

**Общее предусловие для всех кейсов:** браузер открыт на странице входа, корзина пуста (перед кейсом выполнен Reset App State или очищен localStorage).

**Статусы:** Passed, Failed (со ссылкой на баг-репорт), Blocked, Not run.

## Логин

### TC-LOGIN-01. Успешный вход с валидными данными

**Приоритет:** High · **Тип:** позитивный, smoke

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Ввести `standard_user` в поле Username | Значение отображается в поле |
| 2 | Ввести `secret_sauce` в поле Password | Пароль скрыт точками |
| 3 | Нажать Login | Открыта страница `/inventory.html` с заголовком Products, в шапке иконка корзины без счетчика |

### TC-LOGIN-02. Вход с неверным паролем

**Приоритет:** High · **Тип:** негативный · **Техника:** таблица решений

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Ввести `standard_user` в поле Username | Значение отображается в поле |
| 2 | Ввести `wrong_password` в поле Password | Пароль скрыт точками |
| 3 | Нажать Login | Вход не выполнен. Сообщение «Epic sadface: Username and password do not match any user in this service». Оба поля подсвечены красным |

### TC-LOGIN-03. Вход с пустыми полями

**Приоритет:** Medium · **Тип:** негативный · **Техника:** таблица решений

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Оставить поля Username и Password пустыми | — |
| 2 | Нажать Login | Вход не выполнен. Сообщение «Epic sadface: Username is required» |

### TC-LOGIN-04. Вход с пустым паролем

## Оформление заказа

### TC-CHK-01. Успешное оформление заказа

**Приоритет:** High · **Тип:** позитивный, smoke, E2E

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Checkout | Открыта форма Checkout: Your Information |
| 2 | Ввести First Name `Ivan`, Last Name `Petrov`, Zip/Postal Code `100000` | Значения отображаются в полях |
| 3 | Нажать Continue | Открыт Checkout: Overview, в нем товар из корзины |
| 4 | Нажать Finish | Открыта страница Checkout: Complete! с текстом «Thank you for your order!». Счетчик корзины не отображается |
| 5 | Нажать Back Home | Открыт каталог, у всех товаров кнопка Add to cart |

### TC-CHK-04. Расчет итоговой суммы заказа

**Приоритет:** High · **Тип:** позитивный
