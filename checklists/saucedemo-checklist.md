# Чек-лист: Swag Labs

Сайт: https://www.saucedemo.com/. Пароль для всех учетных записей: `secret_sauce`.

Если не указано иное, проверки выполняются под `standard_user`.

## 1. Логин

- [ ] Вход с валидными данными открывает каталог (`/inventory.html`)
- [ ] Вход по клавише Enter работает так же, как по кнопке Login
- [ ] Неверный пароль: сообщение об ошибке, вход не выполнен
- [ ] Несуществующий пользователь: сообщение об ошибке
- [ ] Пустые оба поля: сообщение «Username is required»
- [ ] Пустой пароль: сообщение «Password is required»
- [ ] `locked_out_user`: сообщение о блокировке, вход не выполнен
- [ ] Логин с пробелом в начале или конце
- [ ] Логин в другом регистре (`Standard_User`)
- [ ] Пароль скрыт точками
- [ ] Сообщение об ошибке закрывается крестиком, подсветка полей снимается
- [ ] Прямой переход на `/inventory.html` без входа не открывает каталог

## 2. Каталог

- [ ] Отображаются 6 товаров
- [ ] У каждого товара есть изображение, название, описание, цена и кнопка Add to cart
- [ ] Изображения соответствуют названиям товаров
- [ ] Сортировка по умолчанию: Name (A to Z)
- [ ] Сортировка Name (Z to A)
- [ ] Сортировка Price (low to high)
- [ ] Сортировка Price (high to low)
- [ ] Выбранная сортировка отображается в выпадающем списке

## 3. Карточка товара

- [ ] Клик по названию открывает карточку нужного товара
- [ ] Клик по изображению открывает карточку нужного товара
- [ ] Название, описание, цена и изображение совпадают с каталогом
- [ ] Add to cart и Remove в карточке меняют счетчик корзины
- [ ] Back to products возвращает в каталог

## 4. Корзина

- [ ] Add to cart: счетчик на иконке увеличивается, кнопка меняется на Remove
- [ ] Remove в каталоге: счетчик уменьшается, кнопка меняется на Add to cart
- [ ] При пустой корзине счетчик не отображается
- [ ] В корзине отображаются все добавленные товары с ценой и количеством
- [ ] Remove в корзине удаляет товар
- [ ] Continue Shopping возвращает в каталог, корзина сохраняется
- [ ] Корзина сохраняется после обновления страницы
- [ ] Корзина сохраняется после выхода и повторного входа

## 5. Оформление: данные покупателя

- [ ] Checkout открывает форму First Name, Last Name, Zip/Postal Code
- [ ] Валидные данные: переход к обзору заказа
- [ ] Пустой First Name: «Error: First Name is required»
- [ ] Пустой Last Name: «Error: Last Name is required»
- [ ] Пустой Zip/Postal Code: «Error: Postal Code is required»
- [ ] Поля, заполненные только пробелами
- [ ] Буквы и спецсимволы в почтовом индексе
- [ ] Очень длинные значения (256+ символов)
- [ ] Введенное значение остается в поле после ввода в соседнее
- [ ] Cancel возвращает в корзину

## 6. Оформление: обзор и завершение

- [ ] В обзоре те же товары, что в корзине
- [ ] Item total равен сумме цен товаров
- [ ] Total равен Item total + Tax
- [ ] Суммы отображаются с двумя знаками после запятой
- [ ] Cancel возвращает в каталог
- [ ] Finish: страница «Thank you for your order!»
- [ ] После Finish корзина пуста
- [ ] Back Home возвращает в каталог
- [ ] Оформление заказа с пустой корзиной

## 7. Меню и сессия

- [ ] Меню открывается и закрывается
- [ ] All Items открывает каталог
- [ ] About открывает сайт Sauce Labs
- [ ] Logout возвращает на страницу входа
- [ ] После Logout кнопка браузера «Назад» не открывает каталог
- [ ] Reset App State очищает корзину и счетчик
- [ ] Reset App State возвращает кнопкам товаров состояние Add to cart
- [ ] После удаления cookie `session-username` страница каталога требует вход

## 8. Интерфейс и совместимость

- [ ] Нет опечаток и обрезанного текста
- [ ] Ширина 320 px: нет горизонтальной прокрутки, элементы не накладываются
- [ ] Мобильный пресет (375 px) и поворот экрана
- [ ] Firefox и Edge: основной путь проходит так же, как в Chrome
- [ ] Переход по элементам клавишей Tab, видимый фокус
- [ ] В Console нет ошибок при основном пути
